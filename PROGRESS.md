# malcolmandnuran.com – progress notes

_Last updated 29 Sep 2026_

## How the site works
- Static site generated by `build/build_site.py` → `new_site/` (wiped and rebuilt each run).
  - Reads the old FrontPage download in `Web_site/` (left untouched, **kept on this computer only**, not in git).
  - New tales: plain-text files in `build/tales/` (format in `build/tales/README.md`).
  - Styling: `build/assets/` · home banner photo: `build/source_images/home-hero.jpg`
  - Greyhound videos: hosted on Google Drive, links listed in `build/drive_videos.txt`.
- Tracked in git; pushing to `main` on GitHub publishes `new_site/` to GitHub Pages (`.github/workflows/pages.yml`).
- The PHP tale admin was removed on 29 Sep 2026.

## Everyday: adding a tale
1. Write `build/tales/2026-10-05-some-title.txt` (plus any photos next to it).
2. `python3 build/build_site.py`
3. `git add -A && git commit -m "New tale: …" && git push`
